# Demo 软件开发任务

## 已确定
- 硬件：Seeed XIAO ESP32S3 Sense（OV2640/OV3660，8 MB PSRAM）。板上**没有 IMU**；以后需要时外接 I2C IMU（LSM6DS3 / BMI270）到 D4/D5。
- 第一轮只用一个模组。
- 手机端：原生 Android（Kotlin）。
- ASR / VLM / TTS：先做与厂商无关的接口，选型稍后确定。
- 架构：Pod 持续推帧 → 笔记本 Python 后端（缓冲、记忆、AI 全在后端）← Android App（音频、耳机按键、实验控制）。
