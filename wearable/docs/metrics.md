# Metrics Definition v1（Phase 1：Camera Position Test）

## 基本单位：注意事件（gaze mark）

用户**自然看向**某个目标的那一刻，由主持人在实验台按键打标（记录服务器时间，并减去可调的反应延迟补偿，默认 300 ms）。
每个注意事件在事后标注时选定一帧（默认取离打标时刻最近的一帧，标注员可在 ±1.5 s 内改选），对该帧回答四个问题。

> 这解决了"入画率缺少标准答案"的问题：真值来自主持人对用户视线的现场判断，而不是摄像头画面本身。

## 人工标注字段

| 字段 | 判定标准 |
|---|---|
| target_in_frame 目标入画 | 目标主体（≥ 50% 面积）出现在画面内 |
| centered 目标居中 | 目标中心落在画面中央区域（宽、高各 50%，界面上虚线框） |
| occluded 被遮挡 | 目标被手、脸、衣服、身体遮挡 ≥ 25% |
| useful 可用 | 仅凭这一帧，一个人能回答"这是什么 / 这个怎么接"一类问题 |

目标不入画时，居中、可用自动记为否。

## 指标

分母均为**已标注的注意事件数**，按佩戴位置（可再按任务、受试者）分组。

| 指标 | 公式 |
|---|---|
| Target-in-frame Rate | 入画数 / 已标注数 |
| Target-center Rate | 居中数 / 已标注数 |
| Occlusion Rate | 遮挡数 / 已标注数 |
| Useful Frame Rate | 可用数 / 已标注数 |
| Reposition Rate | "调整"打标数 / 注意事件数（用户为让摄像头看到而主动调整头、身体或摄像头） |
| Auto-QC Rate | 自动质检通过帧 / 本轮全部帧（清晰度 = 拉普拉斯方差 ≥ 60，亮度 40–225）。只作参考，不替代人工判断 |
| Effective fps | 本轮实际收到的帧间隔数 / 时长 |

## 决策分档

来自实验方案 §16。原文的 60–70% 与 80–85% 两个空档在这里补齐：

| Target-in-frame | 判定 |
|---|---|
| < 60% | 不可接受 |
| 60–85% | 勉强（原文 70–80%） |
| ≥ 85% | 产品化候选 |

Reposition Rate > 20%：安装位置可能存在根本问题。

## 实验控制

- 三种位置使用**同一套摄像头参数**（分辨率、JPEG 质量、曝光、帧率）。只允许为倒装设置镜像/翻转。
- 默认参数：VGA、质量 12、2 fps。
- 每位受试者三个位置的顺序按拉丁方轮换，抵消熟练度影响。
